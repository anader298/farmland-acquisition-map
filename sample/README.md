# Synthetic sample

Everything in this folder is generated by `make_synthetic.py` from a fixed
seed. No row is real.

- Counties are fictional: Example, Sample and Demo. The parcel grid is laid
  on a real basemap only so the map has context; the parcels, owners and
  values on it do not exist.
- Owner, LLC and registry names are invented. LLC names start with EXAMPLE or
  DEMO. Bank trusts are "FIRST EXAMPLE BANK".
- Addresses use the made-up town SAMPLETON or ANYTOWN and ZIP codes 00001 to
  00009.
- Sales, soil index, crop history, flood and wetland shares are random draws
  shaped to look like the real distributions.

The files copy the shape of the real public sources, so the pipeline code
runs on both unchanged:

| File | Stands in for |
|---|---|
| `raw/<County>.geojsonl` | county ArcGIS parcel layers, each with its own field names |
| `manifest.json` | the endpoint manifest: field mapping and published row count per county |
| `registry/llcallnam.txt`, `llcallmgr.txt` | Illinois Secretary of State bulk LLC files (fixed width) |
| `sales.csv` | PTAX-203 recorded farm sales with transfer flags |
| `overlays.csv` | spatial joins of each parcel against soil, USDA crop history, FEMA flood and NWI wetland maps |
| `county_rent.csv` | USDA NASS county cash rent |
| `elevators.csv` | grain elevator locations |

Regenerate with `python sample/make_synthetic.py` (same seed, same output).
